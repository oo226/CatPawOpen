# Word 文档一键整理工具

扫描或 OCR 转成 Word 后，经常出现**文本框错位、文字竖排、段落断裂、页码乱飞**等问题。PDF 里看着正常，用 Word / WPS 打开就乱。

这个小工具可以**一键整理**，把乱版文档重新排成正常的段落 Word 文件。

## 你能用它解决什么

- 文字被拆成很多小文本框，排版全乱
- 大段文字旋转 90° 竖着显示
- 列表项 `(一)(二)(三)` 和内容分离
- 页码 `15` 飘在页面中间
- 中文被 OCR 拆成 `选 举 业 主` 这种带空格的格式

## 桌面版（回家有编程电脑再用）

### 打包成 EXE（只需做一次）

1. 电脑上安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 **Add Python to PATH**）
2. 把整个 `docx-cleaner` 文件夹拷到 Windows 电脑
3. 双击运行 `build.bat`
4. 等它跑完，在 `dist` 文件夹里会出现 **`Word文档一键整理.exe`**

### 日常使用

1. 双击 `Word文档一键整理.exe`
2. 点 **选择 Word 文件**（或 **选择文件夹** 批量处理）
3. 可选：指定输出目录（不选则保存在原文件旁边）
4. 点 **开始整理**
5. 会生成 `原文件名_已整理.docx`，**原文件不会被改**

## 工作原理（简要）

1. 读取 `.docx` 内部 XML，提取正文段落、表格、**文本框**里的文字
2. 读取文本框的**位置**和**旋转角度**，把竖排文字还原成横排
3. 按从上到下、从左到右的阅读顺序重新排序
4. 合并断裂段落，识别标题和 `(一)(二)` 列表
5. 输出一份结构正常的新 Word 文档

## 注意事项

- 目前支持 **`.docx`**（Word 2007 及以上）。老的 `.doc` 请先在 Word/WPS 里 **另存为 .docx**
- 整理后版式会简化（标准宋体、正常段落），**不会 100% 还原** PDF 里的精确排版，但内容会连贯可读
- 如果 OCR 本身识别错字，本工具**不会自动改字**，只整理版式
- 建议先备份原文件，整理后对照 PDF 检查一遍

## 常见问题

**Q: 整理后还是有个别字不对？**  
A: 那是 OCR 识别问题，不是排版问题，需要人工改字或重新 OCR。

**Q: 表格没了？**  
A: 复杂表格会被拆成行文本；若表格很重要，整理后需手工微调。

**Q: WPS 和 Word 都能用吗？**  
A: 输入输出都是标准 `.docx`，两个软件都能打开整理后的文件。
